# Photos go here

Drop real photos into this folder using the exact filenames listed in
`../../IMAGES-NEEDED.md`, then run `python3 build.py`. Each placeholder slot is
replaced automatically — no code change needed.

Guidance:

- **Format:** JPG for photos (or WebP if you prefer — update the filename in
  `data.py` to match). Keep each file under ~400 KB; resize to the target size
  listed in `IMAGES-NEEDED.md` before saving.
- **Alt text** is already written for every slot in the page code. If a photo
  shows something different from the alt text, say so and we will update it —
  the alt text has to describe the actual image.
- **Never** hotlink `googleusercontent.com` (or any Google-hosted) URLs. Those
  links rot and are not ours to serve.
- Real job-site photos beat stock every time, including the imperfect ones.
